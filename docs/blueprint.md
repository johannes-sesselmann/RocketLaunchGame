# **App Name**: Rocket Rumble

## Core Features:

- Game Canvas: Renders the game elements, including the player rocket, AI rocket, and randomly placed targets. Implements basic physics (gravity, thrust, rotation).
- AI IQ Selector: Allows the player to select the AI's 'IQ level' from a dropdown menu (e.g., 50, 80, 120). This selection determines the AI's behavior.
- Score Board: Displays the time remaining in the match and the current score for both the player and the AI.
- Start Button: A button that starts the 30-second match.
- AI-Enhanced Opponent: Uses the selected 'IQ level' to retrieve an appropriate AI model and enable smarter gameplay, as if by reasoning from different datasets. It can use its tool to dynamically adjust rocket trajectory in response to the player, in order to secure a higher score

## Style Guidelines:

- Primary color: Dark blue (#003049) to mimic the deep space.
- Secondary color: Sky blue (#87CEEB) for interactive components.
- Accent color: Yellow (#FFC300) for scores and indicators.
- Clear, futuristic font for readability.
- Simple, vector-based icons for targets and game elements.
- Clean, centered layout for game canvas and score elements.
- Smooth transitions and rocket animations for engagement.
